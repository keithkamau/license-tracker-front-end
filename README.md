# License Compliance Tracker - Frontend

React frontend for the Agent License Compliance Tracker.

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router
- React Query
- Zustand
- Axios

## Setup

```bash
npm install
cp .env.example .env
npm run dev

## Build

```bash
npm run build
```

## Environment Variables

Variable----Description
VITE_API_URL----Backend API URL

## Deployment

Deployed on Netlify. Push to main triggers auto-deploy via GitHub Actions.
